# Homelab

Домашний сервер: один узел Kubernetes (k0s), на котором живут сервисы и их базы
данных. Репозиторий ведётся как учебный проект по production-практикам DevOps.

## Language

### Кластеры

**Кластер k0s**:
Единственный узел Kubernetes, на котором живёт всё.
_Avoid_: «кластер» без уточнения, «Kubernetes-кластер».

**Кластер баз**:
Один инстанс PostgreSQL под управлением оператора CNPG: своя версия,
расширения, WAL, PVC, политика бэкапа и окно обслуживания.
_Avoid_: «кластер» без уточнения, «Postgres-кластер».

### Владение

**Граница владения**:
Namespace как единица владения: им владеет ровно один сервис или платформа.
Не разграничивает среды — только ответственность.

**Сервис**:
Деплоируемая единица, которой принадлежит свой namespace и, если нужно, база.
_Avoid_: «приложение» для инфраструктурных сервисов.

**Приложение**:
Сервис для конечного пользователя (Immich, Forgejo, Jellyfin), в отличие от
инфраструктуры и наблюдаемости.

**Платформенный компонент**:
Сервис, который обслуживает сам кластер k0s: трафик, хранилище, секреты,
операторы, GitOps. Лежит вне `apps/`.
_Avoid_: «инфраструктурное приложение».

### Базы данных

**Общий кластер**:
Кластер баз с несколькими потребителями; живёт в нейтральном `databases`.

**Выделенный кластер**:
Кластер баз с одним потребителем; живёт в namespace этого сервиса.

**Единица общей судьбы**:
То, что потребители кластера баз обязаны делить: версия, расширения, blast
radius, профиль нагрузки, политика бэкапа, окно обслуживания. Число кластеров
баз равно числу единиц общей судьбы, а не числу сервисов.

**Служебная база**:
База `app`, которую `bootstrap.initdb` создаёт в каждом кластере баз только
чтобы `initdb` было что создать. Ни один сервис её не использует.

**Роль сервиса**:
Непривилегированная роль PostgreSQL, которой владеет один сервис и которая
владеет его базой.
_Avoid_: суперпользователь `postgres` (зарезервирован оператором CNPG).

**Источник**:
Легаси-деплой в `apps/<сервис>/`, из которого база переносится в кластер баз.
_Avoid_: «старая база».

### Среды

**Среда**:
prod/dev/qa. Разводится отдельными кластерами k0s или машинами, не namespace'ами.

**Тестовый стенд**:
Сервис, который держат для проверки, а не для эксплуатации, и снимают после
(authentik).
_Avoid_: «тестовое окружение».

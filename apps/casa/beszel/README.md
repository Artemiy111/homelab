# Beszel

Beszel собирает метрики хоста и Docker-контейнеров, хранит историю и отправляет
уведомления.
URL: `https://beszel.example.com/`

## Superuser панели /_

PocketBase-панель (`/_/`) — отдельный аккаунт, не связанный с hub-пользователем.

Доступ Agent к `/var/run/docker.sock` даёт ему широкие права над Docker daemon,
даже если сокет смонтирован только для чтения. Используйте только доверенный
официальный образ и обновляйте закреплённую версию вместе с digest.

Первый запуск и проверка — в `RUNBOOK.md`.

## Общий каталог с сокетом

Agent слушает unix-сокет, hub читает его файл, поэтому оба обязаны жить на одном
узле. Каталог передан как статический `local` PV с node affinity: привязка
видна планировщику, и оба пода остаются на узле, где лежит каталог, без ручного
`nodeSelector`. Пересоздание пода на этом больше не ломается — тип пути проверяет
уже не `hostPath`, а node publish (#665).

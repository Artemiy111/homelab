# mihomo

Параллельный исходящий прокси на mihomo с подпиской формата Happ/INCY. Он
существует рядом с `3x-ui` и **не подключён ни к одному потребителю**: Renovate
и Gatus по-прежнему ходят через egress-прокси 3x-ui. mihomo готовится как
замена на будущее, чтобы смену подписки можно было обкатать без риска для
работающих сервисов.

## Зачем

Последний инцидент с прокси был вызван просроченной подпиской: после обновления
подписок в 3x-ui в правилах остался несуществующий `outTag`, и прокси перестал
пускать всех потребителей сразу. Параллельный юнит позволяет проверить новую
подписку отдельно, не затрагивая рабочий путь.

## Как устроен

Провайдер подписки отдаёт разные форматы в зависимости от User-Agent. С UA,
содержащим `mihomo`, он возвращает готовый Clash YAML с полем `proxies` — именно
то, что нужно `proxy-providers` у mihomo. Конвертер не требуется.

Поток данных:

1. `VaultStaticSecret` читает `kv/mihomo/subscription` и кладёт значение ключа
   `SUBSCRIPTION_URL` в Kubernetes Secret.
2. Мост читает URL из Secret, запрашивает подписку с User-Agent `mihomo-bridge`
   и отдаёт блок `proxies` на `/provider`.
3. mihomo раз в интервал забирает этот документ через `proxy-provider` типа
   `http`, проверяет узлы health-check'ом и использует их через группу
   `url-test`.

Адрес подписки есть только в Vault и в смонтированном в мост секрете. В Git
лежат путь к секрету и шаблон конфига, но не сам URL.

Конфиг mihomo отправляет через группу весь трафик, который не попадает под
исключения: cluster-домены `*.cluster.local`, loopback, link-local и частные
подсети идут `DIRECT`. Для внутренних подсетей правила срабатывают без
разрешения DNS.

## Почему именно так

- **Без конвертера.** Провайдер сам умеет отдавать Clash YAML под UA `mihomo`;
  попытка поставить SubConv между подпиской и mihomo оказалась лишней и усложнила
  схему без выигрыша.
- **Мост отдельным контейнером.** URL подписки — секрет, и зашивать его в конфиг
  mihomo в Git нельзя. Мост — единственное место, которое читает секрет и
  подставляет нужный User-Agent.
- **Параллельно, а не вместо 3x-ui.** Ни один существующий манифест не меняется,
  поэтому откат состоит в удалении нового юнита.

## Ограничения

- `external-controller` не требует токена: он закрыт NetworkPolicy и доступен
  только подами внутри namespace. Планируя удалённый доступ к API, нужно сначала
  добавить аутентификацию.
- Состояние провайдера хранится в контейнере mihomo и теряется при рестарте пода;
  после старта узлы загружаются и проверяются заново.
- Юнит не даёт доступ в интернет сам по себе: пока его никто не использует как
  прокси, он только проверяет подписку.

Первый запуск и проверки — в `RUNBOOK.md`.

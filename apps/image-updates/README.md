# Обновления Docker images

WUD проверяет образы запущенных контейнеров и доступен по адресу
`https://wud.example.com/`: хранит историю проверок и в дальнейшем может
отправлять уведомления.

WUD работает только в режиме наблюдения: триггеры не настроены, а Docker API
доступен ему через отдельный read-only socket proxy, запрещающий POST-запросы.
Порт proxy и порт приложения на хосте не публикуются.

Интерфейс защищён на Traefik через forward auth: middleware `oauth2-proxy`
проверяет сессионную cookie и при её отсутствии отправляет браузер на вход в
ZITADEL (`../oauth2-proxy/README.md`). Отдельные секреты для интерфейса не
нужны, хост остаётся в трекаемой конфигурации.

Разворачивается манифестами в apps/image-updates/k8s/.

Чтобы исключить отдельный контейнер из WUD, добавьте ему метку
`wud.watch=false`.

Изменение версии образа и пересоздание выполняются через Git, а не из
интерфейса WUD.

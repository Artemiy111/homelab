# Navidrome

Navidrome индексирует локальную музыкальную библиотеку в
`/storage/media/music` и предоставляет её через веб-интерфейс и клиенты,
совместимые с OpenSubsonic. Библиотека подключена только для чтения: добавлять
в неё музыку может только инструмент импорта или хост.

Сервис доступен через Traefik по адресу `https://${NAVIDROME_HOST}`. За
пределами домашней сети доступ осуществляется через Tailscale; порты на
роутере открывать не нужно.

## Первый запуск

Разворачивается манифестами в apps/navidrome/k8s/.

Каталог с музыкой `/storage/media/music` должен существовать заранее; секреты
хранятся в зашифрованном `secrets.enc.env`.

Создайте учётную запись администратора на экране первого запуска. Публичный
доступ к ссылкам отключён в конфигурации.

## Клиенты

Используйте встроенный веб-плеер или OpenSubsonic-клиент. Navidrome ведёт
[список совместимых приложений](https://www.navidrome.org/apps/).

## Импорт музыки

Используйте соседний сервис [`../spotdl/`](../spotdl/). Он записывает в
тот же каталог хоста, который читает Navidrome. Navidrome отслеживает изменения
и также выполняет полное сканирование каждый час.

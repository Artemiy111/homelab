# Nexus Repository CE (`yc`)

Артефактный репозиторий: хостинг своих пакетов и проксирование внешних
источников (npm, Maven, PyPI, apt, raw, Docker) из одного места. В `yc` он
появился как учебный стенд для этой роли.

## Зачем он здесь

Задача — получить один сервис, который закрывает несколько форматов сразу, и
посмотреть, как он живёт в Kubernetes с внешней базой, а не с встроенной H2, как
в туториалах. Кэширование образов для CI этим не решается: для OCI в `casa`
выбран Zot, и Nexus его не заменяет.

## Как устроено

Состояние разделено на две части. Метаданные (репозитории, настройки, права)
лежат в managed PostgreSQL в Yandex Cloud — два хоста в разных зонах, драйвер
JDBC сам находит primary через `targetServerType=primary`. Содержимое (blob
store) лежит на локальном томе в кластере.

Пароль базы не хранится ни в репозитории, ни в state Terraform: его генерирует
Connection Manager при создании роли, хранит Lockbox, а в кластер приносит
External Secrets Operator. Под получает его переменной окружения из Secret,
который создаёт `ExternalSecret`.

Тома нет в манифесте как отдельного ресурса: PVC создаётся один раз, а под
монтирует его через `claimName`. Стратегия обновления `Recreate`, потому что том
`ReadWriteOnce` и второй под с ним одновременно не поднимется.

## Почему не Helm-чарт

Официальный `nexus-repository-manager` — одиночный инстанс на 3.64, PostgreSQL в
нём не поддержан. HA-чарт `nxrm-ha` требует лицензии Pro и внешней базы. Для CE
с внешней базой остаётся только официальный образ, поэтому манифесты описаны
руками; версия образа закреплена дайджестом.

## Ограничения

- **Один инстанс.** HA в CE нет; отказ узла — простой до переезда пода. Том на
  `local-path` привязан к узлу, поэтому переезд возможен только на тот же узел.
- **Blob store не бэкапится.** PostgreSQL бэкапится managed-сервисом, содержимое
  репозитория — нет. Потеря узла означает потерю загруженных артефактов.
- **Мало места.** Том ограничен свободным местом корневого диска узла; при
  заполнении kubelet начнёт выселять поды.
- **Нет TLS.** Gateway в `yc` слушает HTTP: пароль администратора и токены идут
  открытым текстом. Стенд учебный и не публикуется как доверенный сервис.
- **Лимиты Community Edition** (запросы в сутки и число компонентов) — выше
  порога Sonatype просит перейти на Pro.
- **Данные привязаны к кластеру.** Пересоздание кластера `yc` означает новую
  базу, новый Lockbox-секрет и пустой blob store; перенос — ручная операция.
- **Образ тянется через `mirror.gcr.io`.** Docker Hub из `yc` отвечает таймаутом
  на авторизацию с части узлов; зеркало отдаёт тот же манифест, digest не
  меняется.

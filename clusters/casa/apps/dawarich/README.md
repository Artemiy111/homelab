# Dawarich

История местоположений. База — выделенный кластер CloudNativePG `dawarich-db` в
этом же юните: PostGIS нужен только Dawarich, а расширение уровня базы в общем
кластере делили бы все соседи, и обновление extension-образа перекатывало бы их
вместе с ним.

Dawarich хранит и визуализирует историю местоположений.
URL: `https://dawarich.example.com/`

Первый запуск, проверка и обновление — в `RUNBOOK.md`.

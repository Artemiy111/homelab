# spotDL

`spotDL` — инструмент импорта, а не сервис потокового воспроизведения. Он
читает метаданные Spotify (названия треков и альбомов, обложки), ищет подходящее
аудио на YouTube Music и записывает размеченные аудиофайлы в
`/storage/media/music`. Аудио из Spotify он **не скачивает**.

Используйте его только для аудио, которым владеете, на загрузку которого имеете
разрешение или которое доступно вам иным законным способом. Автоматическое
сопоставление может выбрать другое издание, концертную версию или кавер, поэтому
проверяйте импортированные записи.

У контейнера намеренно нет опубликованного порта и постоянно работающего
веб-интерфейса: так загрузчик без встроенной аутентификации не появляется в
локальной сети. Запускайте его по требованию через Docker Compose.

Файлы создаются в `/storage/media/music`; соседний сервис
[`../navidrome/`](../navidrome/) подключает этот каталог только для чтения.

Подготовка, импорт и обновление — в `RUNBOOK.md`.

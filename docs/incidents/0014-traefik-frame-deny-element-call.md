# 0014: `X-Frame-Options: DENY` на entrypoint Traefik выключил звонки в Element

## Сводка

Общий middleware `secure-headers` подключили к entrypoint вместо маршрутов и
вместе с безопасными заголовками раздали всем хостам `X-Frame-Options: DENY`.
Element Call живёт во фрейме того же origin, браузер фрейм заблокировал: звонок
открывался и висел на загрузке, не доходя до выдачи токена LiveKit.

## Влияние

Element Call не работал ~20 ч — с роллаута Traefik до выправки заголовка.
Остальной Element (вход, комнаты, сообщения) работал: ломался только фрейм
виджета. Затронут один сервис и один пользователь; данные не пострадали.

Мониторинг не увидел: `gatus` проверяет `/livekit/jwt/healthz` и отдачу страницы
Element, а заблокированный фрейм — это клиентское поведение, снаружи оба
эндпоинта отвечают `200`.

## Первопричина

Заголовок включили на уровне entrypoint, чтобы не описывать его в каждом
маршруте. Это решение опиралось на допущение «безопасные заголовки одинаковы
для всех», а оно неверно: `X-Frame-Options` — не про безопасность транспорта, а
про то, кто имеет право встраивать страницу, и у приложений это разное.
`DENY` запрещает фрейм и своему же origin, а Element Call — именно такой фрейм:
Element Web грузит `/widgets/element-call/index.html` с `widgetId` и `parentUrl`.

Проверяли по частям: маршрут Element, выдача токенов, доступность SFU и TURN.
Ни одна проверка не смотрела на заголовки ответа самого widget-документа, а
именно они решали исход. Симптом «вечная загрузка» неотличим от недоступного
SFU, поэтому поиск ушёл в сторону, которая была заведомо исправна.

## Что сработало

- Access-лог Traefik: `GET /widgets/element-call/index.html` есть, ассетов нет,
  `101` на `/livekit/sfu/rtc` нет ни одного — это сузило область до клиента, не
  до сервисов.
- `kubectl exec` в под Element Web и прямой `curl` к поду Gatus отделили
  заголовки Traefik от заголовков приложения.
- Запросы с разными путями на одном хосте (`/ping` и 404) показали, где в цепочке
  применяется middleware: только на маршрутах, которые совпали.

## Уроки

- Заголовок, включённый на entrypoint, проверяется по списку приложений, которые
  встраивают свой UI во фрейм. Такие приложения — исключение из правила
  «одинаково для всех», и их надо искать заранее, а не после жалобы.
- `X-Frame-Options: DENY` и «работает всё, что отдаёт `200`» не противоречат друг
  другу: доступность эндпоинта ничего не говорит о том, отрисует ли его браузер.
- `curl` не воспроизводит блокировку фрейма — её видно только в браузере или по
  отсутствию вложенных запросов в access-логе.

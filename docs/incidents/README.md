# Инциденты

Постмортемы: разборы происшествий, которые **повлияли на сервисы** (простой,
потеря данных, деградация). В отличие от `docs/troubleshot/`, где лежат
диагностические разборы без влияния на работу, здесь у каждого инцидента есть
временная шкала, оценка последствий и действия по итогам.

Формат — blameless postmortem: ищем сломанный процесс или допущение, а не
виноватого. Разделы:

- **Сводка** — одна фраза: что произошло и чем закончилось.
- **Влияние** — кто и как пострадал, сколько длилось.
- **Временная шкала** — события с точным временем из логов и `kubectl events`.
- **Первопричина** — почему это стало возможным, а не кто ошибся.
- **Что сработало** — какие допущения и инструменты помогли.
- **Уроки** — что теперь знаем иначе.
- **Действия** — конкретные задачи, чтобы не повторилось.

Файлы именуются `NNNN-краткое-имя.md` в порядке появления.

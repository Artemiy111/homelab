## Обзор рынка

Рынок self-hosted файловых хранилищ в 2026 году представлен решениями от тяжёлых «groupware-платформ» (Nextcloud) до ультралёгких обёрток над существующими хранилищами (Filestash). Для пользователя, которому нужна **чистая замена Google Drive** без календарей, контактов и прочего groupware, ключевыми критериями являются:

- Современный, чистый UI
- Высокая производительность
- Простота развёртывания (Docker Compose)
- Поддержка синхронизации с десктопа и мобильных устройств
- WebDAV / OIDC / LDAP
- Бесплатность для 5 пользователей

### Исключённые решения

| Решение | Причина исключения |
|---|---|
| **MinIO** | Не является файловым менеджером — это объектное хранилище (S3-сервер). Community edition заморожен. Не подходит как standalone-замена Google Drive. |
| **Pydio Cells** | Home-версия урезана (нет OIDC, LDAP, SSO). Enterprise стоит от €3 280/год за 50 users. Не соответствует требованию «бесплатно для 5 пользователей». |
| **Kodbox** | Китайский проект, документация преимущественно на китайском языке. OIDC/LDAP только в Enterprise-версии. Потенциальные проблемы с локализацией. |

## 1. Nextcloud

### Общая информация

| Параметр | Значение |
|---|---|
| **Архитектура** | PHP-монолит (с microservice-элементами: Talk, Notify_push) |
| **Бэкенд хранилища** | Локальная FS, S3, Swift, SMB/NFS, FTP, WebDAV |
| **База данных** | MySQL/MariaDB, PostgreSQL, SQLite |
| **GitHub** | ⭐ 34 674 звёзд, 1 356 контрибьюторов |
| **Последний релиз** | v34.0.3 (13 авг 2026) |
| **Лицензия** | AGPL-3.0 |
| **Ресурсы** | Мин. 128 МБ RAM/процесс, рекомендуется 512+ МБ/процесс + Redis |
| **Стоимость для 5 пользователей** | ✅ Бесплатно |

### UI/UX

- **Современность UI**: 5/10. Интерфейс переработан в Hub 26 Spring (waffle menu, упрощённые элементы), но по-прежнему ощущается тяжеловесным. Много наложений от приложений.
- **Мобильные приложения**: ✅ Официальные Android и iOS
- **WebDAV**: ✅ Полная поддержка (встроенный DAV-сервер: CalDAV, CardDAV, WebDAV)
- **Десктоп-клиенты**: ✅ Windows, macOS, Linux (с VFS поддержкой)
- **Монтирование в FS**: ✅ Windows (CF API), macOS (File Provider), Linux (экспериментальный). On-demand загрузка файлов при обращении.
- **Превью файлов**: ✅ Огромное количество форматов

### Протоколы и интеграции

| Протокол | Поддержка |
|---|---|
| OIDC | ✅ (через приложения или встроенный) |
| SCIM | ❌ (только через Enterprise) |
| WebDAV | ✅ |
| S3 API | ✅ (как бэкенд) |
| CalDAV/CardDAV | ✅ (групповая функциональность) |
| LDAP/AD | ✅ |
| OAuth2 | ✅ |
| FTP/SFTP | ✅ (как внешнее хранилище) |

### Развёртывание

- Docker: ✅ (через `nextcloud/docker`, не official)
- Docker Compose: ✅ (множество примеров)
- Kubernetes: ✅ (Helm-чарты, operators)
- Systemd: ✅

### Возможности

| Функция | Поддержка |
|---|---|
| Версионирование файлов | ✅ |
| Публичные ссылки | ✅ (пароль, срок действия) |
| Шифрование at rest | ✅ (E2EE доступна) |
| 2FA | ✅ |
| Аудит-логи | ✅ (Enterprise) |
| API | ✅ (REST, OCS) |
| Внешние хранилища | ✅ (FTP, S3, SMB, etc.) |
| OnlyOffice/Collabora | ✅ (Euro-Office, Collabora, OnlyOffice) |

### Русский язык

| Аспект | Статус |
|---|---|
| **UI на русском** | ✅ |
| **Полнота перевода** | ~76% (Transifex, 253K слов) |

| **Русскоязычное комьюнити** | ✅ активное на форуме |

**Плюсы**: Огромная экосистема, максимальная функциональность, огромное комьюнити.  
**Минусы**: Тяжёлый, много groupware по умолчанию, PHP-архитектура ограничивает производительность, UI всё ещё не «легковесный».

## Рекомендации

### Топ-3 рекомендации для замены Nextcloud (чистое хранилище файлов, бесплатно для 5 users)

#### 🥇 1. Filestash — для тех, кто хочет максимальную гибкость

**Идеален если**: файлы уже лежат в S3/SFTP/SMB/NFS, нужен единый красивый UI для доступа к ним.

- Ультралёгкий (128 МБ RAM)
- Лучший UI среди всех решений
- Поддерживает 20+ протоколов хранения
- OIDC/LDAP/SAML
- AI-поиск, workflow engine
- AGPL-3.0 — полностью open source

**Ограничение**: Нет десктоп-клиента для синхронизации (в разработке). Если нужна нативная синхронизация папок — не подходит как sole решение.

#### 🥈 2. Cloudreve — для полноценной замены Google Drive

**Идеален если**: нужна полноценная платформа с синхронизацией, мобильными приложениями и modern UI.

- Go single binary — высокая производительность
- OIDC + 2FA (FIDO2)
- Windows-клиент с on-demand файлами
- Множество бэкендов хранилища (S3, OneDrive, Alibaba Cloud, Tencent)
- 28K звёзд — очень популярный проект
- Активная разработка (релизы каждые 1-2 месяца)
- Kubernetes: нет официального чарта, но Go binary легко контейнеризируется и деплоится вручную

**Ограничение**: Нет macOS/Linux десктоп-клиента, нет LDAP (только OIDC).

#### 🥉 3. Seafile — для максимальной производительности синхронизации

**Идеален если**: приоритет — быстрая синхронизация больших объёмов файлов, готовность к использованию Pro для LDAP, важен качественный русский язык.

- Лучшая в классе delta-синхронизация
- Обновлённый UI в v13/v14
- SeaDrive с виртуальным диском
- AI-функции с v13 (теги, OCR)
- Низкое потребление ресурсов для своей функциональности
- **Лучший русский язык среди всех решений (~100%)**

**Ограничение**: OIDC только через OAuth2 (не стандартный OIDC flow), LDAP в Pro.

### Альтернативные варианты

- **OpenCloud** — если нужна максимальная «предприимчивость» и OIDC/LDAP из коробки, но готовы к 2-4 ГБ RAM. Моложе oCIS, но развивается быстрее (120 контрибьюторов).
- **oCIS** — аналог OpenCloud, проверенный временем (60+ релизов), но более высокие требования к RAM (4-6 ГБ).
- **OxiCloud** — если важна ультра-лёгкость (Rust, 40 МБ image) и не нужны десктоп/мобильные клиенты. Молодой проект, но многообещающий.
- **Hoodik** — если критически важно **E2E шифрование** (пост-квантовое!). Сервер никогда не видит открытые данные. Идеален для конфиденциальных документов. Ограничение: нет WebDAV, OIDC, молодой проект.
- **Nextcloud** — если уже работает и устраивает, но это groupware-платформа, а не чистое хранилище.

### Минимальные рекомендации

Для **homelab с небольшим объёмом файлов** (до 1 ТБ): **Cloudreve** или **Seafile**  
Для **подключения к существующим хранилищам** (S3, NFS, SMB): **Filestash**  
Для **максимальной простоты**: **Cloudreve** (Go single binary)  
Для **Enterprise с OIDC/LDAP**: **OpenCloud** или **oCIS**  
Для **максимального русского языка**: **Seafile** (~100%)  
Для **ультра-лёгкого решения**: **OxiCloud** (Rust, 40 МБ image, 30-50 МБ RAM)  
Для **максимальной безопасности (E2E)**: **Hoodik** (пост-квантовое шифрование, сервер не видит данные)  
Для **монтирования в ФС (VFS/on-demand)**: **Seafile** (лучшая кросс-платформенная VFS) или **Nextcloud** (самая зрелая, но Linux-экспериментальный)

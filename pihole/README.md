# Pi-hole

Pi-hole блокирует рекламу и предоставляет раздельный DNS для локальной сети.
Локальная wildcard-запись разрешает `example.net` и все его поддомены
в `192.0.2.10`.

## Перед запуском

Убедиться, что порт 53 не занят другим сервисом хоста:

```sh
sudo ss -lntup | grep ':53 '
```

Создать файл окружения и постоянный каталог:

```sh
cp .env.example .env
sudo install -d -m 0750 ${APPS_STORAGE_PATH:-/storage/apps}/pihole/etc-pihole
```

`etc-dnsmasq.d/05-homelab.conf` в Git не хранится: `bash init.sh` генерирует
его из `.tpl`-шаблона, подставляя домен из `DOMAIN`. При ручной подготовке
используйте `bash init.sh` вместо `cp .env.example .env`.

Внешняя сеть `traefiknet` должна уже существовать. Запустить Pi-hole:

```sh
docker compose up -d
```

Затем в настройках DHCP роутера указать `192.0.2.10` как DNS-сервер. После
изменения настройки обновить DHCP-аренду на клиентах.

Панель администратора доступна по адресу
`https://pihole.example.net/admin/`. DNS и веб-интерфейс Pi-hole нельзя
публиковать через интернет-роутер.

Если блокировка и локальные имена должны работать постоянно, не следует
добавлять внешний DNS как второй DNS-сервер DHCP: клиенты не считают второй DNS
строго резервным и могут обращаться к нему напрямую.

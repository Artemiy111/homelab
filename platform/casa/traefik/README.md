# Traefik

Активный обратный прокси этого репозитория. Маршрутизаторы используют
HTTPS-точку входа `websecure`, а `web` перенаправляет HTTP-запросы на HTTPS.
Порты 80 и 443 привязаны только к адресу узла и не пробрасываются на
интернет-роутере.

Маршруты приложений живут рядом с приложениями, а не здесь. `Gateway` и
`GatewayClass` тоже описаны отдельно от values чарта: hostname слушателя и
`certificateRef` требуют домена из этих values. В values Traefik выключены
`gateway.enabled` и `gatewayClass.enabled`, иначе чарт создал бы второй Gateway
без сертификата.

## TLS

TLS терминируется на entrypoint `websecure`. Сертификат отдаёт `Gateway`
`homelab` — `certificateRef` на секрет `wildcard-casa-tls` в namespace
`traefik`. TLSStore `default` (`tlsstore.yaml`) указывает на тот же секрет: он
нужен как fallback для SNI, которого нет среди сертификатов, и раньше ссылался
на секрет старого домена — такой запрос получал чужой сертификат.

## Вход через облако

Публичный вход `yc` заканчивается L4-форвардером (`apps/yc/casa-edge`), который
передаёт адрес клиента заголовком PROXY protocol. Такой трафик приходит на
отдельный entrypoint `edge`, а не на `websecure`: kube-proxy на узле маскирует
все обращения к `externalIPs` в адрес узла, поэтому на общем entrypoint
PROXY-заголовок пришлось бы требовать и от локальных клиентов, и от tailnet.

Доверие к заголовку ограничено адресом узла и tailnet. Адрес из заголовка
становится адресом клиента в access-логе, в метриках и для middleware, которые
ограничивают по IP; без него все запросы выглядят как один адрес узла.
Слушатели Gateway на `edge` повторяют `websecure`: маршруты приложений общие,
отличаются только порт и доверие к PROXY.

## Middleware

Общие middleware (forward auth `oauth2-proxy`, `secure-headers`,
`ratelimit-default`) объявлены в namespace `traefik`. `HTTPRoute` ссылается на них
через `ExtensionRef`, а он ищет `Middleware` **в namespace самого маршрута**:
`extensionRef` это `LocalObjectReference` без поля `namespace`. Поэтому в namespace
каждого потребителя лежит своя копия, а `allowCrossNamespace: true` на маршруты
`IngressRoute` больше не распространяется.

## Access-логи

JSON access-лог уходит в stdout, оттуда его забирает Alloy и отправляет в Loki.
Запись отвечает на вопрос «кто стучится»: имя клиента даёт только `User-Agent`,
потому что клиентский IP до Traefik не доходит — L4-форвардер в облаке его не
передаёт (см. `apps/yc/casa-edge/`). По этой же причине в логе нет смысла искать
IP бота: все запросы приходят с адресов узлов облака, а разные боты различаются
только заголовком, путями и частотой.

Заголовки в запись целиком не попадают: `User-Agent` включён поимённо,
остальные вырезаны. Query-строки вырезаются полностью — в них приходят токены и
параметры поиска, для разбора источника они не нужны.

`https://traefik.example.com/dashboard/`. Завершающий слеш обязателен.

# local-path-provisioner (`yc`)

Динамические тома для кластера `yc`: единственный StorageClass, который создаёт
каталог на диске узла и отдаёт его поду как `PersistentVolume`.

## Зачем он здесь

В `yc` нет ни облачного CSI-драйвера, ни Longhorn: до этого юнита в кластере не
было ни одного StorageClass, поэтому ни одно состояние нельзя было сохранить
между рестартами. Nexus требует том под blob store, и локальный провижионер —
минимальный способ его дать: один под, без внешних зависимостей и без обращений
к API облака.

## Как устроено

`StorageClass` с `volumeBindingMode: WaitForFirstConsumer`: узел выбирается в
момент, когда появляется под с томом, а не в момент создания PVC. Провижионер
запускает на выбранном узле короткоживущий helper-под, тот создаёт каталог по
пути из `config.json` и делает его доступным для записи. Дальше под монтирует
каталог напрямую с узла.

Том принадлежит узлу, а не кластеру. Это главное следствие: под с таким томом
переезжает только вместе с данными на том же узле, а при пересоздании ВМ данные
исчезают.

## Ограничения

- **Нет репликации.** Один узел, одна копия. Потеря узла или его диска — потеря
  данных тома.
- **Нет переезда.** PVC привязан к узлу через `nodeAffinity`; если узел выведен
  из строя, под останется `Pending`, пока узел не вернётся.
- **Нет снапшотов и расширения сверх диска.** Размер тома ограничен свободным
  местом корневого диска узла (10 GB на всех трёх узлах).
- **Данные живут на корневом диске** в `/opt/local-path-provisioner`. Заполнение
  тома приближает disk pressure на узле и выселение подов.

Для состояния, которое должно переживать узел, этот класс не годится: там нужен
облачный диск (`yc-csi-driver`) или объектное хранилище. Для blob store Nexus на
учебном стенде ограничение принято осознанно.

## Что не выбрано

- **`yc-csi-driver`** — тома в Yandex Compute Disks переживают узел, но требуют
  ключа сервисного аккаунта в кластере, платят за каждый гигабайт и добавляют
  CSI-контроллер с DaemonSet. Для одного тома это больше инфраструктуры, чем
  пользы; переезд на него — отдельная задача.
- **Longhorn** — три реплики требуют свободного места на всех узлах, а на 10 GB
  дисках его нет.
- **`hostPath` вручную** — не даёт динамического выделения и жизненного цикла
  PVC; провижионер делает то же самое, но через API Kubernetes.
